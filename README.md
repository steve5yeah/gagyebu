# 나의 가계부

브라우저에서 바로 쓰는 단일 HTML 파일 가계부입니다. 설치나 서버 없이 `가계부.html` 파일을 더블클릭해 열면 됩니다.

## 기능

- 수입/지출 입력 (날짜, 구분, 카테고리, 내용, 금액)
- 카테고리 자동 전환 — 수입: 급여·용돈·부수입·기타수입 / 지출: 식비·교통비·주거비·통신비·의료비·문화생활·쇼핑·교육·기타지출
- 월 단위 이동과 해당 월의 수입·지출·잔액 자동 집계
- 내역 목록 조회 및 개별 삭제
- 브라우저 localStorage 자동 저장 — 파일을 닫았다 열어도 데이터 유지
- 모바일 화면 대응 반응형 레이아웃

## 사용 방법

1. `가계부.html`을 내려받습니다.
2. 파일을 더블클릭해 브라우저(크롬·엣지 권장)로 엽니다.

## 데이터 보관

내역은 서버로 전송되지 않고 파일을 연 브라우저의 localStorage에만 저장됩니다. 따라서 다른 기기나 다른 브라우저에서는 내역이 보이지 않으며, 브라우저 사이트 데이터를 삭제하면 함께 지워집니다.
