# 우리집 가계부

30대 2인가구를 위한 단일 HTML 가계부입니다. 설치 없이 브라우저에서 바로 쓰고, 내역은 Supabase에 저장돼 기기가 바뀌어도 그대로 이어집니다.

**바로 사용하기: https://steve5yeah.github.io/gagyebu/**

## 이 가계부가 따르는 기준

단순히 기록만 하는 가계부가 아니라, 2인가구 재정 관리에서 널리 쓰이는 기준을 화면에 녹였습니다.

| 기준 | 반영된 곳 |
| --- | --- |
| **50 · 30 · 20** — 필수 50% / 여유 30% / 저축·투자 20% | 대시보드 배분 게이지 (목표치 세로선 표시) |
| **고정비 · 변동비 분리** — 고정비는 자동이체, 변동비만 관리 | 카테고리별 고정/변동 구분, 구성 비율 카드 |
| **주 단위 변동비 관리** — 월말에 보면 늦다 | 1~4주차 변동비 소진 현황 |
| **비정기 지출 적립** — 명절·경조사·자동차세·여행 | 연간 계획 등록 → 월 적립 권장액 자동 계산 |
| **비상금 4개월치** — 한쪽 소득이 끊겨도 고정비는 그대로 | 최근 3개월 평균 지출 기준 목표액·달성률 |
| **공동생활비 + 개인용돈** | 결제자별 집계와 분담 정산, 개인용돈은 정산 제외 |

## 기능

**대시보드**
- 수입 / 지출 / 저축·투자 / 남은 돈 요약과 저축률
- 이번 달 페이스 — 예산 소진율과 지나간 날짜 기준선 비교, 남은 일수 기준 하루 가용 금액
- 50·30·20 배분, 고정비·변동비 구성, 주간 변동비
- 카테고리별 지출(예산 대비 소진율), 전월 대비 증감 상위 항목
- 비상금 달성률, 최근 6개월 수입·지출 추이, 이번 달 예정된 비정기 지출

**내역**
- 지출 / 수입 / 저축·투자 3종 구분, 결제자(공동·나·배우자), 고정비/변동비 지정
- 날짜별 묶음 보기와 일별 지출 합계, 수정·삭제
- 자주 쓰는 항목 한 번에 채우기, 검색·구분·카테고리 필터

**예산·계획**
- 카테고리별 월 예산과 실적 비교 (초과분은 빗금 표시)
- 주간 변동비 예산 (비워두면 변동비 예산 ÷ 4로 자동 계산)
- 비정기 지출 연간 계획과 월 적립 권장액

**분담·정산**
- 각자 결제한 금액과 공동 결제 금액 집계
- 분담 비율에 따른 정산 금액("누가 누구에게 얼마") 자동 계산
- 이번 달 급여 기준 소득 비례 비율 제안, 개인용돈 현황

**설정**
- 이름·분담 비율·비상금 목표 설정
- 카테고리 추가/삭제 (지출은 고정/변동, 필수/여유 지정)
- 서버에서 다시 불러오기
- JSON 백업 내려받기 / 복원 / 전체 삭제

## 디자인

- 모노톤 — 색이 아니라 굵기·명도·빗금으로 정보를 구분합니다
- 시스템 다크 모드 자동 대응
- 모바일 대응 반응형 레이아웃

## 사용 방법

웹에서 바로 쓰거나(위 주소), `index.html`을 내려받아 더블클릭해 열어도 됩니다. 로그인도 가입도 없고, 어느 쪽으로 열든 같은 내역을 봅니다.

## 데이터 보관

내역은 Supabase(PostgreSQL)에 저장됩니다.

| | |
| --- | --- |
| **원본** | Supabase — 기기·브라우저가 바뀌어도 유지 |
| **사본** | 브라우저 localStorage — 즉시 렌더링과 오프라인용 |

- 화면 오른쪽 위 점이 저장 상태를 보여줍니다: *저장 중 · 동기화됨 · 오프라인 · 동기화 실패*
- 오프라인에서 입력한 내역은 로컬에 남았다가 연결되면 자동으로 올라갑니다
- 저장할 때마다 전체가 아니라 **바뀐 행만** 전송합니다
- 설정 탭의 **백업 파일 내려받기**로 JSON 사본도 따로 보관할 수 있습니다

### ⚠️ 접근 제한이 없습니다

로그인이 없는 대신 **이 가계부에는 아무 보호 장치가 없습니다.**

- 공개 주소를 아는 사람은 누구나 수입·지출·잔고를 보고, 고치고, 지울 수 있습니다
- Supabase publishable key가 HTML에 들어 있고, RLS 정책은 `using (true)` 로 전면 개방되어 있습니다
- Supabase 보안 린터는 이 상태를 경고하지 않습니다 (RLS가 "켜져" 있긴 하므로). 린터가 깨끗하다고 안전한 것이 아닙니다

민감하게 느껴진다면 선택지는 두 가지입니다 — GitHub Pages 배포를 내리고 로컬 `index.html`로만 쓰거나, 접근 제한을 다시 넣는 것.

### 스키마

| 테이블 | 내용 |
| --- | --- |
| `entries` | 내역 1건 = 1행 (`id` PK, `date`, `type`, `category`, `descr`, `amount`, `payer`, `fixed`) |
| `ledger_meta` | `main` 한 행 — `budgets` · `irregular` · `cats` · `settings` (jsonb) |

### 기존 데이터 이관

- 서버가 빈 상태로 처음 열면, 그 브라우저의 localStorage 내역을 자동으로 서버에 올립니다.
- 더 이전 버전(단일 목록형)의 내역도 함께 변환됩니다. 카테고리 대응: 식비→식비·장보기, 교통비→교통·차량, 주거비→주거·관리비, 통신비→통신·구독, 의료비→의료·건강, 문화생활→문화·여가, 쇼핑→쇼핑·의류, 교육→교육·자기계발.
