# 우리집 가계부

30대 2인가구를 위한 단일 HTML 가계부입니다. 설치·서버·회원가입 없이 브라우저에서 바로 씁니다.

**바로 사용하기: https://steve5yeah.github.io/gagyebu/**

## 이 가계부가 따르는 기준

단순히 기록만 하는 가계부가 아니라, 2인가구 재정 관리에서 널리 쓰이는 기준을 화면에 녹였습니다.

| 기준 | 반영된 곳 |
| --- | --- |
| **50 · 30 · 20** — 필수 50% / 여유 30% / 저축·투자 20% | 대시보드 배분 게이지 (목표치 세로선 표시) |
| **고정비 · 변동비 분리** — 고정비는 자동이체, 변동비만 관리 | 카테고리별 고정/변동 구분, 구성 비율 카드 |
| **주 단위 변동비 관리** — 월말에 보면 늦다 | 1~4주차 변동비 소진 현황 |
| **비정기 지출 적립** — 명절·경조사·자동차세·여행 | 연간 계획 등록 → 월 적립 권장액 자동 계산 |
| **비상금 4개월치** — 한쪽 소득이 끊겨도 고정비는 그대로 | 최근 3개월 평균 지출 기준 목표액·달성률 |
| **공동생활비 + 개인용돈** | 결제자별 집계와 분담 정산, 개인용돈은 정산 제외 |

## 기능

**대시보드**
- 수입 / 지출 / 저축·투자 / 남은 돈 요약과 저축률
- 이번 달 페이스 — 예산 소진율과 지나간 날짜 기준선 비교, 남은 일수 기준 하루 가용 금액
- 50·30·20 배분, 고정비·변동비 구성, 주간 변동비
- 카테고리별 지출(예산 대비 소진율), 전월 대비 증감 상위 항목
- 비상금 달성률, 최근 6개월 수입·지출 추이, 이번 달 예정된 비정기 지출

**내역**
- 지출 / 수입 / 저축·투자 3종 구분, 결제자(공동·나·배우자), 고정비/변동비 지정
- 날짜별 묶음 보기와 일별 지출 합계, 수정·삭제
- 자주 쓰는 항목 한 번에 채우기, 검색·구분·카테고리 필터

**예산·계획**
- 카테고리별 월 예산과 실적 비교 (초과분은 빗금 표시)
- 주간 변동비 예산 (비워두면 변동비 예산 ÷ 4로 자동 계산)
- 비정기 지출 연간 계획과 월 적립 권장액

**분담·정산**
- 각자 결제한 금액과 공동 결제 금액 집계
- 분담 비율에 따른 정산 금액("누가 누구에게 얼마") 자동 계산
- 이번 달 급여 기준 소득 비례 비율 제안, 개인용돈 현황

**설정**
- 이름·분담 비율·비상금 목표 설정
- 카테고리 추가/삭제 (지출은 고정/변동, 필수/여유 지정)
- JSON 백업 내려받기 / 복원 / 전체 삭제

## 디자인

- 모노톤 — 색이 아니라 굵기·명도·빗금으로 정보를 구분합니다
- 시스템 다크 모드 자동 대응
- 모바일 대응 반응형 레이아웃

## 사용 방법

웹에서 바로 쓰거나(위 주소), 파일을 내려받아 오프라인으로 쓸 수 있습니다.

1. `index.html`을 내려받습니다.
2. 파일을 더블클릭해 브라우저(크롬·엣지 권장)로 엽니다.

## 데이터 보관

내역은 서버로 전송되지 않고 파일을 연 브라우저의 localStorage에만 저장됩니다. 다른 기기나 다른 브라우저에서는 보이지 않으며, 브라우저 사이트 데이터를 삭제하면 함께 지워집니다. 설정 탭의 **백업 파일 내려받기**로 가끔 JSON을 보관해 두세요.

이전 버전(단일 목록형 가계부)의 내역이 있으면 처음 열 때 자동으로 새 구조로 옮겨집니다. 기존 카테고리는 다음과 같이 대응됩니다: 식비→식비·장보기, 교통비→교통·차량, 주거비→주거·관리비, 통신비→통신·구독, 의료비→의료·건강, 문화생활→문화·여가, 쇼핑→쇼핑·의류, 교육→교육·자기계발.
